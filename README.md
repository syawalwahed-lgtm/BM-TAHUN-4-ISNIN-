# Misi Golongan Kata — BM Tahun 4

Permainan arcade Bahasa Melayu Tahun 4, responsif untuk telefon/tablet, mengandungi nota infografik dan 25 soalan aneka pilihan.

## Jalankan secara tempatan
Buka `index.html` menggunakan pelayar moden (Chrome, Edge, Firefox atau Safari). Audio suara menggunakan Web Speech API jika disokong oleh peranti/pelayar; suara Bahasa Melayu bergantung pada suara yang dipasang. Kesan bunyi ringkas dijana oleh pelayar.

## Terbitkan ke GitHub Pages
1. Log masuk ke GitHub dan cipta repository baharu, contohnya `misi-golongan-kata-bm-tahun4`.
2. Muat naik `index.html` dan `README.md` ke root repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**, branch `main`, folder `/(root)`, kemudian **Save**.
5. Selepas GitHub Pages selesai menerbitkan, pautan laman akan kelihatan di bahagian Pages (biasanya `https://NAMA-PENGGUNA.github.io/NAMA-REPO/`).

## Kandungan
- Nota ringkas: kata nama, kata kerja, kata adjektif dan kata tugas.
- 25 soalan, skor, bintang, maklum balas, bunyi dan bacaan suara jika disokong.
- Latar animasi, warna ceria, paparan responsif dan skrin keputusan.

## Nota kurikulum
Bahan ini direka sebagai latihan tatabahasa. Guru disaran memadankan nombor Standard Kandungan (SK) dan Standard Pembelajaran (SP) dengan DSKP Bahasa Melayu Tahun 4 rasmi serta RPT sekolah sebelum digunakan dalam PdP.
